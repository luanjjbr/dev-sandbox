# 🧪 dev-sandbox

Repositório pessoal destinado a testes, protótipos e desenvolvimento de utilitários diversos em C# e .NET.

## 📌 Projetos e Módulos
- **Interfaces Gráficas (WinForms/WPF):** Testes de telas e dashboards.
- **Ferramentas de Comunicação:** Módulos de conexão serial (UART/COM) e leitor de dados.
- **Utilitários e Scripts:** Algoritmos, manipulação de arquivos e testes de lógica.

## 🚀 Tecnologias Utilizadas
- C# / .NET
- Windows Forms
